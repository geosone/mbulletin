====== mbulletin ======

Generate Mystic BBS bulletins without changing the original blank template.

**Status:** Pascal implementation; offline generation is implemented.

[[https://github.com/geosone/mbulletin|Source and development]]

[[:en:projects:mbulletin|English]] · [[:de:projects:mbulletin|German]]

===== Technical basis =====

Implemented in Free Pascal. A blank template (`BlankFile`) is read from a request
INI with `BlankFile`, `OutFile` and `Report`; the template itself stays
byte-identical and is never embedded into the program. The text file passed as
`TEXT` is integrated into the template of the report named by `Report` and is
fitted to that template's width. Writes are offline and explicit (`--apply`).
Existing targets are refused.

Distribution contains one executable and README.txt: ZIP for Windows, tar.gz for
Linux. No separate manpage, MSI/DEB or system-wide PATH change.
